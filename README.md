# 金融考研择校通（Electron 桌面应用）

金融专业考研择校参考工具：收录全国 31 个省市 126 所一本及以上院校的金融学硕（0202）与金融专硕（0251）招生信息，包括复试线、录取人数、报名人数/报录比、学费、学制、初试科目等，支持筛选、搜索、收藏、对比，并内置**可视化数据编辑器**，方便每年自行更新数据。

## 开发与运行

```bash
npm install        # 安装依赖
npm start          # 启动应用（开发模式）
node test-renderer.js   # 运行功能测试（13 项）
npm run dist       # 打包 Windows 安装包（输出到 dist/）
```

## 数据说明（重要）

- 内置数据整理自公开资料（研招网、各校研究生院官网等），**仅供参考，报考前务必以研招网（yz.chsi.com.cn）和目标院校当年招生简章为准**。
- 每条数据标有参考年份；写「约」「需核实」的字段为网络资料整理值；空缺字段表示公开渠道无可靠数据。
- 历年国家线（经济学门类，学硕/金专共用）内置在「国家线参考」页。

## 数据维护

- **应用内**：「数据管理」页可添加/编辑/删除院校，保存后自动写入本机数据文件。
- **数据文件位置**：`C:\Users\<用户名>\AppData\Roaming\finance-kaoyan-app\data.json`（安装版）。
- **备份/迁移**：「导出备份」生成 JSON；「导入备份」在新电脑恢复。
- **恢复出厂**：「恢复内置数据」可重置（会覆盖自定义修改，先导出）。
- **修改内置默认数据**：直接编辑 `data/batch1-4.json`（省份分组）和 `data/national.json`（国家线），重新打包即生效。

## 项目结构

```
main.js            Electron 主进程（窗口、数据读写、导入导出对话框）
preload.js         安全桥接（contextBridge）
renderer/
  index.html       界面结构（四个视图 + 弹窗）
  styles.css       样式
  app.js           全部交互逻辑（筛选/详情/对比/编辑器）
data/
  national.json    历年国家线
  batch1-4.json    院校数据（华北东北 / 华东 / 中南 / 西南西北）
test-renderer.js   jsdom 功能测试
```

## 数据字段约定

| 字段 | 含义 |
|------|------|
| `m` | 初试数学（303数学三 / 396经济类综合） |
| `j` | 专业课初试科目（如 431金融学综合） |
| `f` | 学费 |
| `d` | 学制 |
| `l` | 各年复试线（对象，键为年份） |
| `la` | 复试线约数（无确切公开值时） |
| `e` / `a` | 录取人数 / 报名人数 |
| `nt` | 备注 |
| `y` | 数据参考年份 |
